# IPL Data Analysis

## 🏏 Project Overview

This project presents an **Indian Premier League (IPL) data analysis** created using Microsoft Excel.

The project explores IPL data to identify patterns, compare team and player performance, and present useful insights through data analysis and visualization.

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Excel formulas
* Charts and data visualization
* Data analysis

## 📁 Project Files

* `ipl.xlsx` — Excel workbook containing the IPL dataset and analysis.

## 🔍 Analysis

The project can be used to explore different aspects of IPL performance, including:

* Team performance
* Player performance
* Match statistics
* Batting and bowling trends
* Winning patterns
* Comparative analysis
* Data visualization

## 🎯 Objective

The objective of this project is to analyze IPL data and convert raw information into meaningful insights using Microsoft Excel.

## 💡 Skills Demonstrated

* Data cleaning and organization
* Excel data analysis
* Pivot Table creation
* Data visualization
* Dashboard/report preparation
* Business-oriented analytical thinking
